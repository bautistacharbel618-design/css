FLUJO NORMAL Y DISPLAY

REGRESAR


1. INTRODUCCIÓN


El flujo normal en CSS es la forma en la que los elementos HTML se acomodan automáticamente dentro de una página. Los elementos se colocan siguiendo el orden en el que aparecen en el código HTML. La propiedad display permite cambiar la forma en la que un elemento se comporta dentro de este flujo. Algunos valores importantes son block, que hace que el elemento comience en una nueva línea y normalmente ocupe todo el ancho disponible; inline, que permite que varios elementos estén en la misma línea; inline-block, que permite colocar elementos en línea y modificar su tamaño; y none, que oculta un elemento y elimina el espacio que ocupaba.
